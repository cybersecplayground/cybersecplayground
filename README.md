## 📚 About

Welcome to **CyberSecPlayground** — your ultimate destination for hands-on **offensive security**, **bug bounty methodology**, and **vulnerability research**.

Curated for ethical hackers, red teamers, and security researchers who want to go deep into:

- 🧠 **Advanced Reconnaissance** — Mapping attack surfaces and finding hidden endpoints
- 🛠️ **Custom Tools & Scripts** — Open-source utilities built by the community
- 📂 **Public CVE PoCs & Writeups** — Real exploits, explained and reproducible
- 🎯 **Exploitation Methodologies** — From recon to post-exploitation
- 🔐 **Web App & API Security** — Modern attack surfaces, modern defenses
- 📝 **Learning Paths & Tutorials** — Structured content from beginner to pro
